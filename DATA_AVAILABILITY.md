## Raw sequencing (GEO / NCBI)

**GSE297328 is currently PRIVATE (held for peer review).** It is **not returned by GEO search**
and cannot be opened without a reviewer token. Reviewers access it via the accession URL and enter
the token in the reviewer-access box on that page:

> **Reviewer access (peer review only):**
> URL — https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE297328
> Reviewer token — **provided in the journal submission** (Methods "Data availability" and the
> response letter). *Per policy the reviewer token is NOT committed to this repository before acceptance.* 

| Data | Accession | Access |
|------|-----------|--------|
| LTL331/R scRNA-seq | GSE297328 (private) | reviewer token in the journal submission; released public on acceptance |

> **At publication the record is released public — update this line to "publicly available under GSE297328."**
